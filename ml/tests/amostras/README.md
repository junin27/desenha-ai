# Amostra do Google Quick, Draw!

`quickdraw_amostra.ndjson`: 3 desenhos reconhecidos de cada uma das 30 categorias do jogo, só com os campos `word` e `drawing` (formato *simplified*).

Fonte: [Quick, Draw! Dataset](https://github.com/googlecreativelab/quickdraw-dataset), Google, licença [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).
